# multidimensional-data-structures
1) Κάνουμε make
2) Εκτελούμε ./run για την εκτέλεση του προγράμματος
Το πρόγραμμα κάνει ανάγνωση το CSV
3) Επιλέγουμε ποιόν αλγόριθμο θέλουμε να χρησιμοποιήσουμε (η τελευταία επιλογή κάνει build όλα τα δέντρα και συγκρίνει χρόνους - ΔΕΝ είναι διαθέσημες οι insert-update-delete σε αυτή την επιλογή)
4) Επιλέγουμε Search και επιλέγουμε ποίο φίλτρο θα χρησιμοποιήσουμε ή και πολλά μαζί
5) Το πρόγραμμα μας εμφανίζει τα αποτελέσματα με βάση τα φίλτρα μας
6) Επιλέγουμε "y" για να χρησιμοποιήσουμε LSH πάνω στα αποτελέσματα
7) Επιλέγουμε το πεδίο και εισάγουμε το keyword που θέλουμε να γίνει η αναζήτηση
Το πρόγραμμα εμφανίζει τα αποτελέσματα με βάση το υψηλότερο matching %
