🚀 Επισκόπηση
Το σύστημα υλοποιεί μια προσέγγιση δύο φάσεων για την ανάκτηση δεδομένων:

Φάση 1 (Χωρικός Φιλτράρισμος): 
Εκτέλεση range queries σε 5 αριθμητικές διαστάσεις (Budget, Revenue, Runtime, Release Year, Vote Average).

Φάση 2 (Similarity Search): 
Αναζήτηση ομοιότητας σε τίτλους, είδη και εταιρείες παραγωγής με τη χρήση της τεχνικής LSH (MinHash) και 3-shingles.

🛠 Δομές Δεδομένων που Υλοποιήθηκαν:

k-d Tree (k=5): Με κυκλική εναλλαγή αξόνων και χρήση της nth_element για τέλεια εξισορρόπηση.

R-tree: Οργάνωση σε Minimum Bounding Rectangles (MBRs) για γρήγορη απόρριψη περιοχών (pruning).

2D Range Tree: Συνδυασμός εμφωλευμένων BST για τις κύριες διαστάσεις και γραμμικό φιλτράρισμα για τις υπόλοιπες.

Quadtree (Hyperoctree): Γενίκευση σε 5 διαστάσεις με 2^5=32 παιδιά ανά κόμβο και χρήση bucket size για βελτιστοποίηση.
